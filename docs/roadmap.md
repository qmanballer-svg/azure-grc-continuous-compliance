# Roadmap

## Phase 1 - Portfolio demo (current)

- Offline JSON evidence
- Python control engine
- CMMC / NIST mapping
- JSON, CSV, and Markdown outputs
- Automated unit tests

## Phase 2 - Read-only Microsoft collectors

- Microsoft Graph identity export
- Azure Resource Graph configuration inventory
- Azure Policy compliance state
- Defender for Cloud recommendations
- Log Analytics / Sentinel evidence queries

## Phase 3 - Continuous monitoring

- Scheduled GitHub Actions or cloud job
- Historical evidence snapshots
- control-state change detection
- exception expiration monitoring
- risk-owner notifications

## Phase 4 - Compliance-as-code

- Terraform / Bicep guardrails
- Azure Policy definitions and initiatives
- pull-request checks for cloud-control regressions
- automated remediation only where risk-approved and operationally safe
